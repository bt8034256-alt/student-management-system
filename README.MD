# Student Management System

A CRUD-based Student Management System built using Node.js, Express, SQLite, HTML, CSS and JavaScript.

## Features
- Add new students
- View all students
- Update student details
- Delete student records
- Store student data in SQLite database

## Technologies Used
- Node.js
- Express.js
- SQLite
- HTML, CSS and JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder in terminal.
3. Install dependencies:

```bash
npm install
```

4. Start the server:

```bash
node server.js
```

5. Open `http://localhost:3000` in your browser.

## Database
The application uses SQLite. The database file is created locally when the application runs.
